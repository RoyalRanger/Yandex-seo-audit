# yandex-seo-audit

Claude Code skill: аудит и доработка сайта под требования Яндекса
(Яндекс.Вебмастер, ИКС, индексация) — technical SEO, не переписывание
контента и не редизайн.

## Что делает

Проверяет и, где нужно, чинит то, что реально влияет на индексацию и
ИКС (индекс качества сайта) в Яндексе:

- `<link rel="canonical">` и `og:url` на каждой странице (частый
  скрытый баг: страница по умолчанию указывает на главную вместо себя)
- `robots.txt` — существует, отдаёт 200, не блокирует лишнего
- `sitemap.xml` — существует, содержит реальные URL
- `favicon.ico` на корне домена как отдельный файл (Яндекс ищет его
  независимо от `<link rel="icon">` в `<head>`)
- Структурированные данные Schema.org / JSON-LD — `Article` для
  статей, `WebSite`/`Organization` для главной
- Живая диагностика через сам Яндекс.Вебмастер, если сайт там
  подтверждён (реальные HTTP-коды обхода, страниц в поиске vs.
  добавлено, рекомендации)

Никогда не трогает визуальный дизайн и не переписывает контент "под
SEO" — Яндекс сам штрафует переоптимизированный текст.

## Как использовать

Skill подключается в Claude Code (`.claude/skills/yandex-seo-audit`),
срабатывает на запросы вида "оптимизируй сайт под Яндекс", "проверь
SEO для Яндекса", "почему сайт не индексируется в Яндексе" — детали
триггеров и процесса в [`SKILL.md`](./SKILL.md).

Правило №1: скилл всегда перечитывает актуальные страницы
support.yandex.ru/webmaster перед аудитом, не полагается на память
предыдущего прогона — правила Яндекса меняются без анонсов.

Работает на любом стеке: обкатан на FastAPI+Jinja2 (серверные шаблоны)
и на React/Vite SPA — готовые сниппеты в
[`references/code-patterns.md`](./references/code-patterns.md)
переносятся по смыслу, не копипастой. Чек-лист с обоснованием каждого
пункта — [`references/yandex-checklist.md`](./references/yandex-checklist.md).
